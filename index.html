Build worlds that remember.

Howling Whispers is a connected ecosystem for worldbuilding, character simulation, persistent interactive worlds, and research.

Enter Orbis or join the Howling Whispers Discord.

The core ecosystem

Orbis: Canon & Library

The canonical library and worldbuilding platform. Orbis stores worlds, characters, places, items, factions, species, societies, families, memories, and connected canon.

Speculus: Simulation

A roleplay and simulation environment that loads Orbis canon to test characters, scenes, relationships, context, and behavior.

Fabula: Persistent World Runtime

The runtime layer for long-running worlds with travel, time, inventory, economy, encounters, dice, consequences, and persistent state.

Studium: Research & Analysis

The research system that studies simulation and runtime history, identifies patterns and gaps, and can prepare new canon proposals for review.
